// Bağlanma

Kurulum gerekmez — hosted.

MCP sunucu adresi:

https://sokrates.fastmcp.app/mcp

Hangi asistanı kullanıyorsunuz?

Claude.ai'ı açın, Connectors ekleyin

Sohbet kutusunun yanındaki + menüsü → Connectors → Add connector. İsim sokrates, URL yukarıdaki adres.

Connector'ı aktif edin

Aynı menüdeki Connectors listesinde sokrates'i açık konuma getirin.

Belirsiz hedefinizi anlatın

Yeni bir sohbette, ör. "bir gym app yapmak istiyorum" yazın.

Claude Desktop/Code için .mcp.json kılavuzu — detaylar ↗

Developer mode'u açın

Settings → Apps → Advanced settings'ten Developer mode'u etkinleştirin (Pro/Plus/Business/Enterprise/Education).

Custom connector oluşturun

Settings → Connectors → Create. İsim sokrates, URL yukarıdaki adres, kimlik doğrulama: "No auth".

Belirsiz hedefinizi anlatın

Yeni bir sohbette connector'ı seçip hedefinizi yazın.

Connectors sayfasını açın

Le Chat'te Connectors → + Add Connector → Custom MCP Connector sekmesi.

Sunucuyu tanımlayın

Connector name: sokrates, Server URL: yukarıdaki adres → Connect.

Belirsiz hedefinizi anlatın

Sokrates artık araç listesinde.

Tüketici Gemini uygulamasında (web/mobil) şu an custom MCP sunucusu eklemek desteklenmiyor. İki yol var:

Gemini CLI — ~/.gemini/settings.json'a ekleyin:

{ "mcpServers": { "sokrates": { "httpUrl": "https://sokrates.fastmcp.app/mcp" } } }

Kurumsal Gemini Enterprise — admin, Connected apps → Add MCP Server.

MCP bağlantısı şu an sadece Qwen masaüstü uygulamasında mevcut, web sürümünde yok. Masaüstü uygulaması → MCP ayarları → "Custom MCP": isim sokrates, URL yukarıdaki adres.

MCP bağlantısı şu an sadece Kimi CLI üzerinden mevcut:

kimi mcp add --transport http sokrates https://sokrates.fastmcp.app/mcp

Groq bir sohbet arayüzü değil, bir model sağlayıcı. Sokrates model-bağımsız olduğu için Groq modelini kullanan herhangi bir MCP istemcisiyle (ör. Groq Desktop) yukarıdaki URL'i normal bir uzak MCP sunucusu olarak ekleyebilirsiniz.
